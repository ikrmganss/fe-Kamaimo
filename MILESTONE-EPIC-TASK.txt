FITUR YANG DICATAT ULANG DARI WEB
---------------------------------
A. MODE USER - PUBLIK TANPA LOGIN
1. Home:
   - Navbar fixed dengan menu Beranda, Wisata Unggulan, Desa Wisata,
     Atraksi, Paket Wisata, Kuliner, dan Hotel.
   - Navbar berubah menjadi solid/blur saat scroll.
   - Dropdown bahasa Indonesia/Inggris.
   - Hero fullscreen dengan gambar Luk Panenteng, judul animasi
     "Sulawesi Tengah", dan tagline.
   - Peta desa wisata dengan marker titik biru dan pulse.
   - Tooltip peta berisi preview media, nama, dan lokasi.
   - Carousel Wisata Unggulan.
   - Carousel Desa Wisata.
   - Carousel Atraksi/Event.
   - Ranking Top 5 Negara Asal Turis.
   - Ulasan Pengunjung.
   - Footer, media sosial, dan state Loading/Empty/Error.
2. Detail Desa Wisata:
   - Hero media foto/video/YouTube.
   - Nama desa, lokasi, dan deskripsi.
   - How to Get There dari Palu dan Luwuk.
   - Transportasi darat, laut, dan udara.
   - Ulasan pengunjung.
   - Loading skeleton dan halaman Desa Tidak Ditemukan.
3. Detail Event/Atraksi:
   - Hero media.
   - Nama event, lokasi, deskripsi, dan rentang tanggal.
   - Countdown hingga tanggal mulai.
   - Loading skeleton dan halaman Event Tidak Ditemukan.
4. Paket Wisata:
   - Search berdasarkan nama.
   - Toggle carousel/grid.
   - Card media, nama, deskripsi, harga Rupiah, dan tombol WhatsApp.
   - Modal detail paket dan CTA WhatsApp.
5. Kuliner:
   - Search makanan.
   - Toggle carousel/grid.
   - Card foto, nama, lokasi, dan badge Rumah Makan.
   - Modal detail, daftar rumah makan, dan tombol Google Maps.
6. Hotel:
   - Search nama hotel.
   - Toggle carousel/grid.
   - Harga minimum/maksimum, jumlah kamar, dan jumlah tempat tidur.
   - CTA telepon, Google Maps, dan website.
7. Ulasan:
   - Carousel ulasan dengan avatar, nama, komentar, dan rating bintang.
   - Tambah ulasan tanpa login.
   - Validasi nama, komentar, dan rating.
8. Bahasa dan tracking:
   - Bahasa ID/EN dengan fallback ke bahasa Indonesia.
   - Visitor UUID.
   - Pageview untuk halaman utama.

B. MODE ADMIN - LOGIN TERSEMBUNYI
1. Pintu rahasia dari Home, lalu login username/password.
2. Proteksi route dengan JWT dan role.
3. Dashboard grafik pengunjung:
   - Today, Yesterday, This Week, Last Week, This Month, All Days.
   - Visits dan visitors.
   - Filter per hari, bulan, dan tahun.
   - Bar chart.
4. CRUD 9 entitas:
   - Desa Wisata.
   - Jarak Desa.
   - Atraksi.
   - Paket Wisata.
   - Kuliner.
   - Rumah Makan.
   - Hotel.
   - Kunjungan Turis.
   - Ulasan.
5. Pola CRUD:
   - Tabel, search, pagination 5 per halaman.
   - Modal tambah, edit, detail, dan konfirmasi hapus.
   - Upload foto/video atau link YouTube secara eksklusif.
   - Auto-translate ID ke EN dengan debounce 1,5 detik.
6. Super Admin:
   - Kelola akun admin.
   - Search, pagination, tambah, edit, detail, dan hapus.
   - SuperAdmin tidak dapat diedit atau dihapus.
7. Profil Admin:
   - Edit nama, jenis kelamin, username, dan password.
   - Ganti password memaksa logout.

C. BACKEND
- Reuse backend Express, Prisma, dan PostgreSQL yang sudah ada.
- Domain public: desaWisata, jarak, atraksi, tourPackage, kuliner,
  rumahMakan, hotel, ulasan, visitor, dan pageview.
- Tracking: visitor UUID dan pageview.
- Fitur tambahan: model dan route Kunjungan Turis.
- Bug adminAuth.js: req.header.authorization dan startWith perlu
